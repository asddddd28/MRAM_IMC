## 额外验证

- 576项全激活的极值：+8640 / -9216。
- 任意精度 Python 参考累计到 2^100 量级仍精确；NumPy 更新超出 int64 主动报错；大加权归约不回卷。
- 配置、浮点输入、越界权重、错误形状、非法状态和未定义算法扩展均拒绝。
- 无提交预览、输入迭代器失败、第二折溢出、模拟失败不会提交部分事务。
- 比较器的正 offset、最小脉宽、参考量化/建立、比较期间的持续参考建立。
- FC fan-in 为1、37、576、577、1201的映射与直接点积一致。
- 两层8→4→2网络，batch=2，两种SCU位宽，连续6步逐层与独立矩阵IF oracle一致。
- 2输入/2输出通道小卷积，stride=2/padding=1，12个空间上下文连续2步与直接卷积递推一致。
- 固定逻辑后备容量超限诊断；不会将软件数组数量解释成硬件并行度。
- `reference` / `simulate` / `infer` 两种命令行入口、报告输出和失败退出码。

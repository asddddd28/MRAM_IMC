# Reference：五位补码 MRAM–IMCCluster 的等效模型与 Python 实现规范

> 版本：v1.0；整理日期：2026-09-09。  
> 用途：作为后续 Python 行为仿真、网络推理、硬件感知训练与调度研究的统一实现依据。  
> 当前交付是模型规范，不是已经实现、标定或验证过的芯片仿真器。

## 1. 本文的使用边界与依据

建模对象是用户最新示意图及文字描述中的 IMCCluster：16 个 Macro，每个 Macro 有五个位平面，每个位平面保留自己的 SCU 低位状态和 MR 高位状态；正负 TDP 生成时间信号，经 TW/SG 转成局部有符号电荷，16 路合成后进行一次神经元发放判决。

信息优先级如下：

1. 用户最新的五位结构说明与图 `442705ba-fd65-45e4-b308-62f6372c92c7.png`。
2. 用户本轮接受的等效模型规划。
3. `MRAM_SNN_CIM_MSB双延时异或完整设计方案_局部膜电位保持与长期无发放增强版.pdf`：用于理解双延时、符号、电荷共享和状态保持的原理。
4. `三模式可重构MRAM存内计算SNN架构完整方案(2).pdf` 与 `MRAM_3StateIMC.pdf`：用于后续调度和存储接口背景。

旧 PDF 或旧 `NOTICE.md` 中的四位权重、其他 SCU 位宽、粗状态合并方式及并行输出数，不能自动覆盖最新五位结构。本文不把此前讨论过的 MR 合并存储、重编码、维护单元或新门控电路作为现有硬件。

本文使用三种表述：

- **确定项**：由最新说明或已明确的连接关系给出。
- **建模约定**：为使第一版模型可运行而选择的明确语义；不代表晶体管电路已经这样实现。
- **待确认项**：由实际电路、控制器或标定数据补齐，必须保留配置入口。

实现者应先完成原结构的功能与物理转换一致性，再研究调度、训练或架构变体。

## 2. 系统粒度与基本参数

| 参数 | 本文定义 | 状态 |
|---|---|---|
| `num_macros` | 16 | 确定项 |
| `inputs_per_macro` | 每轮最多 36 个二值输入与对应权重项 | 沿用当前讨论的输入规模 |
| `weight_bits` | 5 | 确定项 |
| `bit_weights` | `(1, 2, 4, 8, -16)`，下标从 LSB 到 MSB | 确定项 |
| 权重整数范围 | `[-16, 15]` | 五位补码的结果 |
| `scu_bits` | 3 或 4；首轮用 4 验证，再切换 3 | 用户给出的候选范围；默认值为实验选择 |
| `mr_bits` | 每个位平面 MR 的位数 | 待确认；不要把原描述中的 Q 与其他数量混用 |
| 一轮最大 fan-in | `16 × 36 = 576` 个输入—权重项 | 上述规模的结果 |
| 一个 Cluster 的判决 | 16 个 Macro 共同完成一个逻辑神经元的判决 | 确定项 |
| `leak_mode` | 第一版显式设为 `none` | 无泄漏工作点；真实泄漏规则待确认 |
| `reset_mode` | 本文采用发放后硬清零 | 按当前描述，清零范围见第 7 节 |
| 偏置 | 首版关闭 | 当前数据通路未给出偏置注入位置 |

576 是输入项数量，不必然是卷积特征通道数量。例如 `3×3` 卷积、64 个输入通道，展开后恰好有 `9×64=576` 项；一种固定映射是每个 Macro 处理 4 个输入通道的 9 个位置。

本规范中的一个 Cluster 没有 16 个独立输出神经元。Python 同时计算多个逻辑神经元，是软件批处理能力；不能据此推导芯片具有同等数量的并行电路。

## 3. 模型层次及各自的责任

| 层次 | 推荐名称 | 内容 | 能证明什么 |
|---|---|---|---|
| L0 | `integer_reference` | 足够宽的精确整数、原五路状态与理想阈值 | 数学功能、状态守恒、复位语义 |
| L1 | `finite_digital` | 加入实际 SCU/MR 位宽、存储访问和溢出检查 | 数字范围、上下文保存、控制顺序 |
| L2 | `ideal_behavioral` | 无误差 TDP、充电、共享、参考和比较 | 在声明的有效量程与时序条件下，物理链等价于整数链 |
| L3 | `nonideal_behavioral` | 参数化非线性、失配、噪声、有限建立时间和存储错误 | 假设参数下的误差传播及敏感性 |
| L4 | `calibrated_behavioral` | 用 SPICE、版图提取或实测数据替换参数/LUT | 在标定覆盖范围内预测行为 |

训练是上述前向模型外的梯度封装，不是另一个可以擅自改变前向语义的硬件模型。

L0 可以用 Python 整数。向量化版本若使用 `int64`，必须检查中间值和累计上界；不能把 `int64` 宣称为无限精度。模拟量参考实现使用 `float64`，后续再验证降低浮点精度的影响。

首版不在 Python 中求解整张网络的 MTJ 磁化动力学或全部 MOS 晶体管。器件/电路仿真提供读写特性、时间传递函数、电流曲线和 RC 参数，Python 使用对应的行为方程或查找表。

## 4. 数学符号、单位和状态所有权

| 符号 | 含义 | 单位/范围 |
|---|---|---|
| `n` | SNN 逻辑时间步 | 整数索引 |
| `t` | 电路事件发生的物理时间 | 秒；归一化模式中为明确声明的时间单位 |
| `m` | Macro 编号 | `0..15` |
| `b` | 位平面编号 | `0..4` |
| `i` | Macro 内输入位置 | `0..35` |
| `f` | 输入折编号 | 仅在启用输入折叠接口时使用 |
| `β_b` | 五位补码位权 | `1,2,4,8,-16` |
| `s, L` | SCU 位宽及模量 | `L=2^s` |
| `q_MR` | 每个 MR 的位宽 | 用 `mr_bits` 配置 |
| `a[m,b]` | SCU 低位残余计数 | `0..L-1` |
| `h[m,b]` | MR 高位计数 | 暂按无符号；有限模型为 `0..2^q_MR-1` |
| `k[m,b]` | 本次 PMAC 计数 | `0..36` |
| `c[m,b]` | 本次向 MR 传递的完整进位商 | 非负整数，不是布尔标志 |
| `U_m, U` | 局部、全局完整候选膜电位 | 整数膜电位单位 |
| `S_m, S` | 局部、全局低位残余加权值 | 整数膜电位单位 |
| `G` | 所有 MR 按位权合并后的粗计数 | 整数；乘 `L` 后才是膜电位贡献 |
| `P_m, N_m` | 正、负 TDP 的理想加权输入 | 非负计数单位 |
| `q_cap[m]` | 局部跨接电容指定极板的有符号电荷 | 库仑，另一极板为相反电荷 |
| `v_sig, v_ref` | 在同一差分端口定义下的信号和参考 | 伏特 |
| `Θ` | 发放阈值 | 与 `U` 同一整数尺度 |

不要把 `q_cap` 定义成两端电荷之差后仍沿用单极板电荷的公式，否则会引入二倍增益错误。差分共模电压单独记录，不与 `v_sig` 的差模定义混写。

### 4.1 三类状态必须区分

1. **逻辑神经元状态**：每个上下文自己的 `a/h`，跨 SNN 时间步保存。
2. **当前物理工作状态**：被 Controller 载入的行、工作寄存器、候选值、忙闲标志。
3. **本次转换的模拟状态**：电容电压、TDP 边沿、SG 状态和参考建立过程。

上下文可以定义为：

```text
(sample_or_stream, layer, output_channel, output_y, output_x)
```

FC 层可省略空间坐标。样本/流之间的初始化和神经元发放后的硬复位属于不同事件。

### 4.2 推荐张量形状

```text
active SCU:  [batch, context, 16, 5]
active MR:   [batch, context, 16, 5]
spike tile:  [batch, context, 16, 36]
weight bits:[weight_line, 16, 36, 5]
```

权重不必在 batch 或所有空间位置上物理复制。`context` 是逻辑索引，不等于硬件有这么多同时驻留的寄存器组；物理容量由存储与调度模型另行约束。

保留时间维的完整 trace 是可选调试功能，不能默认把所有层、时间步的 80 路状态永久展开到 GPU 内存。

## 5. 五位补码、SSU 与 PMAC

### 5.1 权重表示

对整数权重 `w`，先得到五位编码：

```python
assert -16 <= w <= 15
u5 = w & 0b11111
bit_b = (u5 >> b) & 1
```

随后必须满足：

\[
w=\sum_{b=0}^{4}\beta_b\operatorname{bit}_b(w).
\]

| 权重 | 编码，MSB→LSB | 加权解释 |
|---:|---|---|
| -16 | `10000` | `-16` |
| -1 | `11111` | `-16+8+4+2+1=-1` |
| 0 | `00000` | `0` |
| 1 | `00001` | `1` |
| 15 | `01111` | `8+4+2+1=15` |

负权重不是“符号位加正幅值”。MSB 本身承担 `-16` 的位权。

### 5.2 读出与计数

MRAM 权重读取后的位值进入 SSU/PMAC。功能模型按照读取到的位值计算：

\[
k_{m,b}=\sum_{i=0}^{35}x_{m,i}\,\widehat B_{m,i,b},\quad x_{m,i}\in\{0,1\}.
\]

无读错时 `B_hat=B`。不满 36 项的位置用有效位屏蔽或补零，必须保证不会读入上一上下文的残留输入。

首版 PMAC 是精确数字 popcount。时序违例导致的数字错误应作为独立故障模型，不能不加说明地给计数结果叠加连续高斯噪声。

位平面在 Python 中同时计算或按 `0..4` 循环计算，都只是执行方式。实际 PMAC、感放、加法器复制了几份，以及是否按位串行，由资源描述决定；不能仅从五份状态推导五套运算电路面积。

## 6. SCU/MR 的更新与守恒

### 6.1 无泄漏、无故障的单次更新

对每个 `(m,b)`：

\[
z_{m,b}=a_{m,b}+k_{m,b},
\]

\[
c_{m,b}=\left\lfloor\frac{z_{m,b}}{L}\right\rfloor,\qquad
a'_{m,b}=z_{m,b}\bmod L,\qquad
h'_{m,b}=h_{m,b}+c_{m,b}.
\]

恒等式：

\[
a'_{m,b}+Lh'_{m,b}=a_{m,b}+Lh_{m,b}+k_{m,b}.
\]

| SCU 位宽 | 最大 `z` | 最大进位商 | 进位商最少位数 |
|---:|---:|---:|---:|
| 3 | `7+36=43` | 5 | 3 |
| 4 | `15+36=51` | 3 | 2 |

两种情况下，保存 `z` 的无符号临时运算都至少需要 6 位。若硬件逐个事件计数并逐次处理进位，可以使用单次 carry；若接收整个 PMAC 计数，则必须保留完整商。

仅考虑一轮 576 项全激活输入，完整加权增量就可以达到 `576×15=8640` 或 `576×(-16)=-9216`，至少需要 15 位有符号范围。这与 SCU 的 3/4 位、单次 PMAC 的 6 位是不同层次；加入历史和输入折后，还要重新计算完整膜电位的上界。

### 6.2 合并值只是派生量

\[
S_m=\sum_b\beta_ba_{m,b},\quad
C_m=\sum_b\beta_bh_{m,b},\quad
U_m=S_m+LC_m.
\]

\[
S=\sum_m S_m,\quad G=\sum_m C_m,\quad U=S+LG.
\]

本规范仍然保存五份 `h[m,b]`。`C_m`、`G` 用于观测及阈值路径的计算，不作为合并 MR 存储或重编码的授权。

在零输入、无泄漏、无偏置且无错误时，`a/h` 应保持不变。是否能够跳过一次物理转换是另一个需要控制器依据的调度问题。

### 6.3 位宽边界

| 量 | `s=3` | `s=4` |
|---|---:|---:|
| 局部 `S_m` 范围 | `[-112,105]` | `[-240,225]` |
| 局部 `S_m` 最少有符号位数 | 8 | 9 |
| 全局 `S` 范围 | `[-1792,1680]` | `[-3840,3600]` |
| `P_m` 最大值 | 105 | 225 |
| `N_m` 最大值 | 112 | 240 |

若各 `h` 是 `q_MR` 位无符号数，令 `Hmax=2^q_MR-1`，则：

\[
C_m\in[-16H_{max},15H_{max}],\qquad
G\in[-256H_{max},240H_{max}].
\]

完整 `C_m` 使用 `q_MR+5` 位有符号整数足够，完整 `G` 使用 `q_MR+9` 位足够。计算 `LG`、`Θ-LG` 和网络累计上界时还需单独增加位宽。若归约树暂时保存未抵消的正项和负项，各节点也要按自己的最大输入范围选宽。

### 6.4 MR 溢出语义

支持以下明确区分的运行模式：

- `wide_reference`：保留足够宽计数，另行报告真实 MR 容量会在哪里超限。
- `error`：有限位宽主验证模式；在实际更新超限处报错并保存诊断。
- `wrap`：只有需要分析硬件回卷后果或真实硬件就是回卷时才启用。
- `saturate`：仅在明确实现了饱和逻辑的变体中启用；不属于本规范默认硬件。

检测发生在实际每次 MR 更新后，而不是只检查最后全局 `U`。全局正负抵消不能消除已经发生的某一 MR 溢出。

`error` 是仿真诊断策略，不代表现有电路已经实现溢出检测或停机逻辑。该模式发现超限后中止当前实验并保存候选状态，不继续给出被标为有效的推理结果。

输入折数为 `F`、距最近一次完整复位最多 `T` 步、每折每位最多 36 次计数时，保守上界是：

\[
a+Lh\le36FT,\qquad
s+q_{MR}\ge\left\lceil\log_2(36FT+1)\right\rceil.
\]

这是从零开始且存在上述时间界的容量条件。连续流若没有复位或其他约束，不能把固定测试窗口长度当成实际最大静默时间。

## 7. 一个逻辑时间步的事务与硬复位

模型区分已提交状态 `state` 与正在形成的 `candidate`：

1. 根据上下文载入权重行与膜电位工作状态。
2. 读取本轮输入，完成各位平面 PMAC 与 SCU/MR 更新。
3. 若启用输入折叠，把所有输入折继续累加到同一候选状态。
4. 候选状态完整后，启动/完成规定的 TDP、电荷、参考与判决过程。
5. 用该模型实际产生的 `fire` 决定提交还是复位。
6. 按控制器约定写回或继续驻留，完成本次事务。

建模约定是每个逻辑时间步在完整输入后判决一次；中间位相或输入折不能提前发放。若真实电路判决粒度不同，需要修改这一显式约定并重新验证网络语义。

\[
(a,h)_{n+1}=\begin{cases}
(0,0),&\text{fire}=1,\\
(a^*,h^*),&\text{fire}=0.
\end{cases}
\]

这里清零的是当前逻辑神经元所属的全部 `16×5` 个 SCU 和全部 `16×5` 个 MR，不清除其他神经元状态，也不清除权重。

非理想模型使用 `fire_hw` 更新自己的状态；整数参考使用 `fire_ref` 更新自己的状态。不能让模拟误差只改变输出 spike，却继续按理想判决复位。

每轮转换前的模拟电容预充电与神经元硬复位分开建模。数字状态已经包含历史时，不再把上次电容的完整历史重复积分进来。

## 8. MRAM、工作寄存器和地址模型

### 8.1 权重地址和状态地址分开

推荐逻辑地址：

```text
weight_line_id = (layer, output_channel, input_fold)
state_line_id  = (sample_or_stream, layer, output_channel, y, x)
bank/cell      = (macro, bit_plane, item_or_state_field)
```

这些是逻辑地址结构，实际 line 如何跨 bank 分布由映射表给出。卷积中权重可在不同 `(y,x)` 复用，状态不可跟着权重行混用。

最新图给出了 MRAM Weight Array、Mem. Array 和本地 MR。模型应保留状态载入、工作更新和写回事件。MR 在上下文切换时存到哪里、Mem. Array 一行包含什么、是否允许多上下文驻留，均需实际接口确认；不能在功能数组存在的同时默认芯片也具有无限后备存储。

### 8.2 存储错误按作用位置注入

| 错误 | 应影响什么 | 状态后果 |
|---|---|---|
| 权重瞬态读错 | 本次读出的位 | 不默认改写物理存储内容 |
| 固定坏位 | 指定物理 cell 的读写结果 | 同一虚拟芯片重复出现 |
| 状态瞬态读错 | 本次工作状态 | 若被正常提交/写回，错误可能延续 |
| 状态写入失败 | 目标存储位 | 后续换入读到旧值或错误值 |
| 保持错误 | 存储状态随驻留时间变化 | 按实际保持间隔触发 |

读错率可分别配置 `p_0_to_1` 和 `p_1_to_0`。错误概率与电压、温度、读取时长的关系若没有数据，作为可选假设，不标为器件测量结论。

读取延迟、写入延迟、bank 冲突和 Controller 占用由事件与资源模型统计。软件一次张量读取不是一次硬件 MRAM 读取。

## 9. 正负 TDP、TW 和 SG

### 9.1 理想时间关系

对更新后的 SCU 残余：

\[
P_m=a_{m,0}+2a_{m,1}+4a_{m,2}+8a_{m,3},\quad N_m=16a_{m,4}.
\]

\[
t_{+,m}=t_{launch,m}+t_{base}+\tau P_m,
\quad
t_{-,m}=t_{launch,m}+t_{base}+\tau N_m.
\]

定义 `d_m=t_plus-t_minus`：

\[
TW_m=|d_m|,\qquad \sigma_m=\operatorname{sign}(d_m).
\]

`d>0` 表示正支路结束更晚，净残余为正；`d<0` 表示负支路结束更晚，净残余为负；理想 `d=0` 时脉宽为零，符号不产生电荷贡献。

`σ=+1/-1` 是模型的数学符号。它与图上 SG/SGB 的高低电平及交叉开关连接方向之间，另用实际电路真值表映射，不能凭信号名称默认 SG=1 就一定代表正贡献。

这一公式适用于共同起点的脉冲，或启动后先后到达并保持的边沿。若真实输入是两个错开的窄脉冲，XOR 可能生成多个脉冲，必须按实际波形事件求输出，不能直接套 `|d|`。

图中的 TDL/WPCM 按实际功能抽象；不凭缩写推断未给出的电路结构。图上 TDP 标签、负支路级联关系与最新五位说明之间的细节，通过转移函数和后续时序资料确定。

### 9.2 保留位平面构成的非理想模型

正路允许使用：

\[
t_{+,m}=t_{launch,m}+\epsilon_{common}
 +f_{+,m}(a_0,a_1,a_2,a_3;\theta_{device},V,T)+\epsilon_{+,m}.
\]

负路允许使用：

\[
t_{-,m}=t_{launch,m}+\epsilon_{common}
 +f_{-,m}(a_4;\theta_{device},V,T)+\epsilon_{-,m}.
\]

根据实际电路，`f_plus` 可由各位平面 LUT、各级传递函数或联合查表构成。简化成 `f_plus(P)` 会忽略不同位平面组成的差异：例如 `a0=2,a1=0` 与 `a0=0,a1=1` 都有 `P=2`，但存在级间失配时未必产生相同延时。

公共抖动由同一个随机变量进入两路，在理想差值中抵消；支路抖动保留。之后由同一对受扰动的边沿产生 TW 和 SG，保留符号与幅度误差的相关性。

先支持以下参数：静态增益/偏移、每码非线性、公共/差分抖动、最小有效脉宽、SG 判别死区、SG 有效时间。死区内若没有标定概率，报告 `ambiguous_sign`，不要宣称已经建立准确的亚稳态概率模型。

## 10. 局部电荷、保持及共享网络

### 10.1 理想电荷转换

定义 `q_cap[m]` 为完成符号定向后的局部跨接电容正端极板电荷：

\[
q_{cap,m}=\sigma_m I_m TW_m.
\]

在正负增益匹配、恒流且工作在有效量程内时：

\[
q_{cap,m}=I_0\tau S_m.
\]

第一版先把 TW 视为充电使能、SG 视为连接极性。如果实际 SG 在充电或共享期间变化，详细模型按开关事件更新拓扑，不能继续把它当作从始至终固定的符号。

### 10.2 充电与等待期间的动态

对适用的局部等效支路：

\[
C\frac{dV}{dt}=I(V,t)-\frac{V-V_{base}}{R_{leak}}.
\]

恒定电流与线性泄漏时，时间区间 `Δt` 上可解析推进：

\[
V(t+\Delta t)=V_{base}+IR_{leak}
 +[V(t)-V_{base}-IR_{leak}]e^{-\Delta t/(R_{leak}C)}.
\]

等待期间令 `I=0`。无泄漏极限直接用 `ΔV=IΔt/C`，避免数值上用极大电阻求极限。开关注入按对应边沿添加电荷；电流顺从范围、局部最大电压和脉宽截断分别检查。

不同 Macro 的完成时间不同，因此到共享时的保持时长也不同。早完成的支路可能泄漏更多；这正是后续调度与物理误差产生联系的位置。

### 10.3 共享必须从电荷守恒出发

对于明确的理想并联跨接拓扑：

\[
v_{sig,\infty}=\frac{\sum_m q_{cap,m}+q_{initial}}{C_{eq,total}}.
\]

首版理想预充电令 `q_initial=0`。`C_eq,total` 是在上述电荷与差分端口定义下的等效电容；只有拓扑支持时，才简化为 `ΣC_m+C_par,diff`。对地寄生、跨线寄生和比较器输入电容应先转换到同一网络模型，不能不加区分地全部直接相加。

零贡献但仍连接的电容仍属于网络。固定电流、充分共享时，电容失配不自动等价于同等比例的逐 Macro MAC 增益失配；它还影响局部电压、量程及建立速度，需按守恒计算，避免重复叠加增益噪声。

简单建立模型可写成：

\[
v_{sig}(t)=v_{sig,\infty}+
[v_{sig}(t_{share})-v_{sig,\infty}]
e^{-(t-t_{share})/\tau_{share}}.
\]

一阶模型仅在经过验证或标定后使用。更准确的线性 RC 网络可写为 `dv/dt=A v+b`，在每次开关事件之间解析推进；明显非线性时才引入数值 ODE。

### 10.4 共享时序是待确认接口

理想行为测试可以声明如下时序假设：局部预充电、完成转换、符号稳定、所有支路就绪后统一共享、稳定后比较。

但最新图中 TWB 与接入共享网络的具体逻辑未完全确定。上述测试假设不能被写成“现有硬件已经有独立全局 SHARE”。实现应保留两种明确标签：

- `synchronized_ideal_assumption`：用于验证期望数学行为。
- `explicit_switch_events`：按真实 TW/TWB/SG/其他控制边沿执行，暴露提前共享、符号未稳等问题。

后者必须忠实运行提供的波形，不能为了通过测试自动增加等待或新控制信号。

## 11. MR 归约、参考端与比较器

### 11.1 阈值等效关系

\[
U=S+LG\ge\Theta
\iff
S\ge\Theta_{eff}=\Theta-LG.
\]

这就是 MR 合并后进入参考端的数学依据。若使用第 10 节的理想链，定义：

\[
\alpha=\frac{I_0\tau}{C_{eq,total}},\qquad
v_{sig}=\alpha S,\qquad v_{ref}=\alpha\Theta_{eff}.
\]

所有量使用同一差分端口约定。实际参考的码—电压映射可以有偏移和不对称范围，但应通过校准明确，不混入未声明的共模项。

### 11.2 实际参考模型

按顺序执行：

1. 在声明的数字位宽下计算 `G`、`L*G` 和 `theta_eff`。
2. 将 `theta_eff` 映射为参考控制码，保留量化与范围检查。
3. 用参考电路的 LUT/函数得到稳态目标电压。
4. 从上一次实际参考状态推进建立过程，得到比较时刻的 `v_ref`。

参数至少包括输入码范围、输出电压范围、分辨率、码相关非线性、偏移、建立时间和初始状态。具体是否采用某种 DAC/CDAC 拓扑待确认，因此代码可命名 `ReferenceModel`，不强制插入未经确定的硬件。

若参考越界：记录 `reference_out_of_range`。只有实际电路具有对应行为时才模拟 clipping 或其他处理。当前不默认存在数字“必发放/必不发放”旁路。

### 11.3 比较器与输出

约定正 offset 抬高有效发放门槛：

\[
margin=v_{sig}-v_{ref}-v_{os}+\eta_{cmp},\qquad
fire=\mathbf1[margin\ge0].
\]

无 offset/noise 时等号发放。若实际比较器定义不同，显式修改并使参考测试一致。

`v_os` 是固定或缓慢变化的偏移，`η_cmp` 是对应判决事件的随机噪声。判决延迟可使用 `delay(abs(margin), common_mode, V, T)` 查表。未经标定时，用不确定带和超时事件描述边界，不编造亚稳态概率。

仿真输出的电压/电荷 trace 是软件观测量，不意味着硬件增加了 ADC。

## 12. 泄漏、偏置及重置的扩展边界

第一版使用 `leak_mode=none`、`bias=0`、硬复位，验证原转换和计数过程。这是 IF 工作点，不代表已经定义了所有 LIF 行为。

后续若启用神经元泄漏，必须一起规定：

- 作用于全局 `U`、每个局部 `U_m`，还是逐位平面状态。
- 在本时间步输入之前还是之后作用。
- 每逻辑时间步一次，还是按连续物理时间作用。
- 舍入方式、负值行为及如何回写原五组 `a/h`。
- 是否存在钳位、下界或溢出扩展。

逐位平面衰减并舍入、逐 Macro 衰减、全局衰减通常不能默认互换。任何需要重编码的泄漏实现也必须说明硬件如何执行；不能在 Python 中免费增加维护运算。

电容等待时泄漏属于物理转换误差，不自动等价于训练模型中的膜电位泄漏。两个参数名称、时间尺度与开关独立。

偏置同理：先确定注入位置和数值尺度，不能直接把标准 `Linear/Conv2d` 的 bias 接到未定义的硬件路径。

## 13. 器件参数、相关误差与随机数

### 13.1 参数分层

| 层级 | 例子 | 生命周期 |
|---|---|---|
| 全芯片 | 工艺角、参考增益、共享供电项 | 每个虚拟芯片生成一次或按慢变量更新 |
| 物理 Macro/支路 | 电流偏差、正负延时差、局部开关参数 | 绑定物理编号，跨逻辑上下文保持 |
| bank/cell | 固定坏位、读写特性差异 | 绑定物理地址 |
| 慢变化 | 温度、供电漂移、老化 | 随物理时间或实验工况更新 |
| 事件 | 单次抖动、读错、判决噪声 | 每个对应事件采样 |

同一芯片上的公共时钟、组内供电、局部支路、参考噪声可以相关。首版未建模的相关项设为关闭，而不是声称独立高斯模型覆盖全部噪声。

### 13.2 可复现性

至少区分 `chip_seed`、`event_seed` 和数据/训练随机种子。设备实例一旦生成应可保存并重新载入。

为了使标量执行器、GPU 张量执行器和不同调度顺序能够公平比较，建议用稳定事件标识关联随机样本，例如：

```text
(chip_id, physical_block_id, operation_id, logical_step, read_or_conversion_index)
```

不能仅依赖“随机数生成器被调用了几次”，否则向量化或循环顺序变化就可能改变整个误差序列。不同调度若确实改变物理时间或事件数，则相应噪声/漂移差异属于模型结果，应在实验中说明。

多芯片 Monte Carlo 与同芯片重复推理分别报告。每个 SNN 时间步重抽整颗芯片失配，不代表固定芯片部署。

## 14. 事件驱动时序与资源模型

SNN 的 `n→n+1` 表示神经元递推；物理时间 `t` 表示 Controller 与电路执行。输入折或位平面循环不能被错误地当成多个 SNN 时间步，也不能自动多次执行神经元泄漏。

推荐事件：

```text
context_load, weight_read_start, weight_read_done,
state_read_start, state_read_done, pmac_done,
scu_update, mr_update, candidate_ready,
tdp_launch, positive_edge, negative_edge, sign_valid,
charge_done, switch_change, reference_ready,
compare_start, compare_done, hard_reset,
state_commit, state_write_start, state_write_done
```

每个事件记录时间、物理资源、逻辑上下文和依赖。资源表描述 bank 端口、PMAC/SCU 运算单元、TDP、局部充电端、共享网络、参考端与比较器。

数字粗归约可与模拟转换并行到什么程度，取决于实际资源和稳定要求。16 路并行延迟通常由依赖链与最晚完成支路决定，不能把 16 个 Macro 延迟直接全部相加。

无真实资源表时，模型只输出功能顺序和参数化延迟，结果标为假设时序。软件 GPU 耗时不作为芯片延迟。

必须能报告：读写冲突、候选状态未完整、旧 MR 配新 SCU、符号未稳定、共享尚未建立、参考未就绪、比较超时和状态写回未完成。

## 15. FC/卷积映射、输入折叠与三模式接口

### 15.1 固定映射先行

FC 的一个输出神经元对应输入向量与权重行。卷积的一个 `(cout,y,x)` 对应一个展开窗口。采用固定、可逆的输入项顺序，并记录：

```text
flat_input_index -> (input_fold, macro_id, local_input_id)
```

第一版先用 `fan_in≤576`，尾部补零。扩展到 `N>576` 时：

\[
F=\left\lceil N/576\right\rceil.
\]

第 `f` 折读取该折权重和 spike，更新同一候选状态；不能每一折重新读入本时间步开始前的旧膜电位，也不能在中间折发放。

这是待与 Controller 对齐的输入折叠接口约定。功能模型能够折叠不意味着实际存储容量、行切换带宽和控制器已支持该吞吐。

### 15.2 状态保存与驻留

输出通道折叠、空间位置折叠都需要保存各自完整 `a/h`。在无其他编码时，每个逻辑神经元至少需要：

\[
80(s+q_{MR})\ \text{bit}
\]

的 SCU/MR 状态位，不含地址、有效位、备份、ECC、端口及外围。Python 用 `int64` 数组占用的 RAM 不是硬件状态位数。

驻留多个时间步是否减少 MRAM 访问，必须基于真实可用工作寄存器及写回协议。不能为调度实验隐含增加多套状态缓存。

### 15.3 三模式的位置

原三模式方案未来作为 `SchedulePolicy` 的不同配置接入，共用同一 `ClusterModel` 和数学语义。每种模式应明确层/时间块/输出上下文/输入折的循环顺序、数据就绪条件、存储容量及驻留策略。

在未完成这些接口定义前，不根据模式名称假定存在额外 ADC、16 路独立 LIF 或旧文档的并行 MAC 路径。第一版验收不依赖三模式均已实现。

### 16.1 核心对象

```python

)
```

接口草案，不是可直接执行的完整代码：

```python
result = cluster.step(

```

`input_tiles` 可以是单折或受控迭代器；`step()` 的边界始终是一整个逻辑时间步的输入与一次最终判决。若拆为多次 `accumulate_tile()`，必须使用事务标识并显式 `finalize()`，防止误把每一折当成一次神经元输出。

### 16.2 参考执行流程伪代码

```python
working = load_current_context(state)
candidate = copy_for_update(working)

for tile in input_tiles:
    observed_bits = memory.read_weights(tile.weight_line_id)
    counts = pmac(tile.spikes, observed_bits)
    candidate = update_scu_mr(candidate, counts)
    check_each_actual_mr_update(candidate)

# 无泄漏工作点；若将来启用泄漏，位置与回写规则须另行明确。
fine_sum, coarse_sum = reduce_original_five_plane_state(candidate)
theta_eff = theta - (1 << scu_bits) * coarse_sum

edges = tdp.convert(candidate.scu, device)
charges = charge.convert_and_hold(edges, device, schedule)
v_sig = sharing.evaluate(charges, actual_switch_events)
v_ref = reference.evaluate(theta_eff, compare_time)
fire_hw = comparator.compare(v_sig, v_ref)

next_state = hard_reset(candidate) if fire_hw else candidate
commit_according_to_memory_protocol(next_state)
return spikes, next_state, diagnostics
```

物理阶段的伪代码顺序表示数据依赖，不规定全部硬件操作串行执行。电路事件引擎负责可并行的粗归约、TDP、参考建立等。

## 18. 硬件感知训练接口

### 18.1 前向保真，反向近似

PyTorch 自定义自动求导允许分别定义前向与反向；发放替代梯度可以参考 snnTorch 的实现方式。相关官方资料见第 25 节。

前向包含真实五位量化、补码拆位、五组 SCU/MR、物理转换和实际比较器输出。反向使用明确记录的近似梯度，不把它称为电路精确导数。

至少处理两类不连续：

1. 量化、整数拆位、进位与有限范围。
2. 阈值发放和硬复位的时间递推。

只给最终 spike 加替代梯度，无法自动打通前面的整数路径。

### 18.2 量化与尺度

训练权重可保留浮点主参数 `w_float`，前向得到：

\[
w_{int}=\operatorname{clip}\left(\operatorname{round}(w_{float}/s_w),-16,15\right).
\]

硬件按 `w_int` 计算。阈值、偏置（若将来支持）及其他状态必须转换到同一计数尺度。首版使用固定层尺度；若训练尺度或阈值，需同步定义其量化与硬件表示。

五位拆位只作用于 `w_int`。不应把负数当符号幅度，也不应在物理电流增益与网络尺度中重复乘同一个 `s_w`。

### 18.3 可微代理与跨时间步状态

局部加权输入的梯度代理可用：

\[
\Delta U_m^{proxy}=\sum_i x_iw_{int,i}
\]

并为权重量化使用范围受限的 STE。发放导数作用于比较 margin 的代理，尺度应从电压换算为约定的计数或归一化单位。

可采用前向值校正：

\[
y=y_{proxy}+\operatorname{stopgrad}(y_{hw}-y_{proxy}).
\]

前向数值等于 `y_hw`，梯度来自 `y_proxy`。该做法必须用于正确的递归状态/margin 接口，而非只修正最终分类 logits。实现可保留原整数 `a/h` 作为权威前向状态，另维护与局部总值对齐的可微影子状态以传播 BPTT 梯度。

代理状态也应按照实际 `fire_hw` 的前向值复位；是否对 reset 的导数截断，使用显式 `detach_reset` 配置并记录。推理前向不得因该训练开关改变。

在 MR 回卷、参考饱和、强非线性或符号死区附近，简单代理可能不准确。第一阶段先在无溢出且有效量程内验证训练，再研究这些边界。

### 18.4 MR 正则化的限制

首版监测各位平面 MR 的最大值、增长率和高水位事件。直接把硬整数 MR 加入 loss，通常不会产生有效的权重梯度。

若后续要训练“减少某个位平面增长”，需要位值的平滑代理、离散权重分布或其他明确梯度估计；仅对总 `U_m` 加约束不能完整约束五路冗余计数。该项作为后续研究，不混入初版正确性验收。

### 18.5 训练运行要求

- 固定芯片训练时，设备失配绑定物理实例，瞬态噪声按事件采样。
- 鲁棒训练可在声明的批次/轮次边界抽取不同虚拟芯片，测试分别报告固定芯片和跨芯片结果。
- 训练、验证、测试使用独立数据与随机种子；校准数据不能泄漏测试标签。
- 截断 BPTT 可以切断梯度图，但不能把持续流的前向硬件状态误清零。
- 梯度检查点重计算或重复调用 `forward()` 时，不得重复提交状态、重复写入模拟存储或重新抽样同一事件噪声。训练核心优先采用显式状态输入/输出，并保存可复用的事件随机样本；需要物理事件副作用时由外层事务管理。
- 标量参考与张量版校验前向数值；替代梯度不要求等于离散硬阈值的有限差分导数，应单独验证其所声明的代理反向规则。

## 19. Trace、指标与报告

提供 `off / summary / selected_context / full_debug` 等级。全量 trace 仅用于小实验。

| 类别 | 至少记录 |
|---|---|
| 状态 | 上下文、`a/h`、PMAC 计数、进位商、候选 `U_m/U`、复位 |
| 溢出 | 位平面、物理 Macro、逻辑步/折/位相、更新前后值、容量 |
| 时间 | `t_plus/t_minus`、TW、SG 有效时间、保持时长、共享/参考/比较时刻 |
| 模拟 | 局部电荷/电压、共享电压、参考目标/实际值、margin、范围错误 |
| 事件 | 行读取、写入、资源等待、转换、控制切换、比较、状态提交 |
| 推理 | spike 序列、首次分歧、误发放/漏发放、最终任务指标 |
| 复现 | 配置摘要、模型版本、设备/校准标识、随机种子 |

建议输出：逐步 spike 一致率、首次状态分歧位置、MR 占用分布、溢出率、正负时间差及较大正负内部计数的分布、参考越界率、比较 margin 分布和网络任务精度。

要同时做两种比较：

- **同状态单步比较**：从相同候选状态进入理想与非理想链，定位当前电路误差。
- **独立轨迹比较**：两个模型各按自身判决继续运行，评估累计影响。

## 20. 延迟、能耗、面积与翻转统计边界

### 20.1 延迟

从事件依赖图和资源占用计算完成时间、关键路径及吞吐。报告实际等待、转换、建立和写回，而不是 Python 函数耗时。

### 20.2 能耗

未标定阶段输出操作计数和活动量：MRAM 行/位读取、写入、SCU/MR 更新、TDP 转换、充电时间、参考变码、比较次数与总运行时长。

取得成本后可计算：

\[
E_{total}=\sum_e E_e(\text{code, transition, duration, device})
 +\int P_{idle/bias}(t)\,dt.
\]

同一模块的实测“每次转换能量”若已包含内部充电/偏置，不再次重复计入。`C V^2/2` 是储能关系，不自动等于整个供电网络完成一次操作消耗的能量。

### 20.3 翻转与面积

对明确位宽寄存器可统计 `popcount(old XOR new)`；有符号数使用对应宽度的补码编码。寄存器翻转只是活动指标，不等于门级毛刺数量；模拟开关次数与数字位翻转分开。

面积由物理实例数量、综合和版图数据估算。逻辑上下文数、Python 对象数或 tensor 字节数不能直接换算芯片面积。实际 bank、感放、PMAC、加法器和端口共享关系未确定时，面积结果保持未标定状态。

## 21. 电路标定数据格式与获取顺序

先标定孤立模块，再做组合链交叉验证，防止用一个整体拟合系数掩盖不同误差来源。

| 模块 | 扫描输入/条件 | 保存输出 |
|---|---|---|
| MRAM 读写 | 地址、数据、读写时长、V/T | 延迟、读写错误统计、能量 |
| TDP | 各位平面码及组合、V/T、重复试验 | 正负边沿、脉宽、固定偏差和抖动 |
| 局部充电 | TW、初始电压、极性、V/T | 电压/电荷曲线、量程、能量 |
| SG/开关 | 切换时序、负载、输入极性 | 注入、符号有效时间、异常脉冲 |
| 共享网络 | 初始电荷模式、支路组合、开关时刻 | 差模/共模建立曲线、寄生效应 |
| 参考端 | 输入码、前一码、等待时间 | 稳态电压、动态建立、范围与非线性 |
| 比较器 | 差分 margin、共模、V/T | 输出、延迟、offset/noise、超时 |

文件可用 CSV 保存曲线、JSON/YAML 保存元数据、NPZ 保存多维 LUT。每份数据至少含：单位、物理/仿真条件、端口符号定义、测量窗口、样本数、随机种子或 Monte Carlo 条件、校准版本和有效输入范围。

插值方式、重复测量如何分解固定偏差和瞬态噪声，都要记录。LUT 越界默认报告；不能静默外推或夹紧后仍声称位于已标定区域。

未知时可以先关闭误差，并对单项参数做带明确标签的假设扫描；不能编造真实工艺参数或百分比收益。

## 22. 验收用例与明确预期

以下是后续实现必须包含的行为验收规范。除另有说明，使用无泄漏、无偏置、无噪声、充分建立、阈值等号发放、零初始状态。本文提供数值预期，不代表仿真器已经通过这些验收。

### T01：全部补码值

对 `w=-16..15` 全部编码、拆位、按 `β` 重建，应逐值相等。另验证零 spike 不贡献计数，输入为 1 时重建贡献等于 `w`。

### T02：多进位与 MSB 位权

| 条件 | 预期 |
|---|---|
| `s=3,a=7,h=2,k=36` | `z=43,c=5,a'=3,h'=7`；完整计数 `23→59` |
| `s=4,a=15,h=2,k=36` | `z=51,c=3,a'=3,h'=5`；完整计数 `47→83` |
| 上一行发生在 MSB | 加权贡献 `-752→-1328`，本次变化 `-576=-16×36` |

在给定容量下分别检查 MR 是否容纳 `h'`，不能只检查数学恒等式。

### T03：有符号局部转换

`s=4`，某 Macro 的 `a=(3,2,0,1,1)`，MR 为零：

```text
P = 3 + 2×2 + 8×1 = 15
N = 16
S_m = -1
```

归一化 `tau=1,current=1` 时，应产生单位脉宽、负符号和 `q_cap=-1`。交换到正净残余的测试应得到正极性。

### T04：16 路 MR 修正与负参考

`s=4`，16 个 Macro 全部设置：

```text
a = (3,0,0,0,1)
h = (1,1,0,0,0)
```

每个 Macro 有 `P=3,N=16,S_m=-13,C_m=3,U_m=35`，因此：

```text
S = -208
G = 48
U = -208 + 16×48 = 560
```

- `theta=560`：`theta_eff=-208`，等号发放。
- `theta=561`：`theta_eff=-207`，不发放。

归一化总电容为 16 时，`v_sig=-13`；两种参考分别为 `-13` 与 `-12.9375`。该用例验证所有局部残余电荷为负时，MR 高位修正仍可使完整膜电位达到正阈值。实际参考不支持所需负范围时，应报告量程问题，而非强行通过理想用例。

### T05：净输入为零但原始计数增长

同一 Macro 每步两个 spike，权重分别 `+1,-1`，其余输入为零，`theta>0`。每步位平面计数增加 `(2,1,1,1,1)`，净膜电位始终为零。

`s=4,mr_bits=4` 时，在第 127 步结束：

```text
a = (14,15,15,15,15)
h = (15,7,7,7,7)
U_m = 0
```

第 128 步候选应为 `a=(0,0,0,0,0)`、`h=(16,8,8,8,8)`；第 0 位 MR 超过 15，有限严格模型必须报告溢出，即使宽参考 `U_m=0`。

若显式启用四位 MR 回卷，第 0 位变为 0，该候选重建值成为 `-256`。这是要被观测的故障，不是可以忽略的内部抵消。

### T06：跨 Macro 抵消与真实局部增长

Macro 0 每步贡献 `+10`，Macro 1 每步贡献 `-10`，其余为零，阈值保持正数。全局 `U=0`，但两个完整局部膜电位分别为 `+10n`、`-10n`。

必须保存各自五路状态，并观察它们的范围；不能把全局零值回写为所有 Macro 零状态。

### T07：物理误发放后的轨迹分歧

`theta=10`，初始零状态，只使用一个权重 `+3` 的输入：

1. 第一步输入该 spike，理想候选 `U=3`、不发放。
2. 用受控故障使物理比较器在第一步误发放，物理状态必须清零，参考保留 3。
3. 第二步无输入且关闭故障，参考候选仍为 3，物理候选为 0。

该测试不要求随机噪声碰巧产生误判，使用明确的 comparator 故障注入即可。它验证误差进入递归状态，而非只改变输出。

再做连续输入版本：每步均输入一次 `+3`，只在第三步给物理比较裕量增加等效 `+2` 个膜电位单位。若比较器模型的输入是伏特，需将该扰动乘信号链标度 `α` 后注入。

| 逻辑步 | 参考候选 U | 参考 spike | 物理候选 U | 物理 spike | 物理提交后 U |
|---:|---:|---:|---:|---:|---:|
| 1 | 3 | 0 | 3 | 0 | 3 |
| 2 | 6 | 0 | 6 | 0 | 6 |
| 3 | 9 | 0 | 9 | 1 | 0 |
| 4 | 12 | 1 | 3 | 0 | 3 |
| 5 | 3 | 0 | 6 | 0 | 6 |
| 6 | 6 | 0 | 9 | 0 | 9 |
| 7 | 9 | 0 | 12 | 1 | 0 |

参考 spike 序列为 `0001000`，物理序列为 `0010001`。即使只有一次瞬态扰动，后续发放时刻仍可能持续偏离。

### T08：输入折叠事务

`theta=10`，同一步两折净贡献分别为 `+12`、`-5`，最终候选为 7，应不发放。若实现第一折结束即发放，会错误复位并改变最终状态。

另验证交换数学加法顺序在宽整数模型中保持最终结果；有限硬件的中间溢出、物理保持时长与事件顺序差异必须单独记录，不能据此默认任意重排都等价。

### T09：权重复用而状态隔离

两个输出空间位置使用同一权重行，在不同输入历史下形成不同 `a/h`。交替换入换出后应分别恢复，硬复位其中一个不影响另一个。

### T10：边沿相关性与等值抵消

- 给正负边沿同时加同一公共延时，理想 TW 和电荷应不变，完成时刻改变。
- `P=N` 且完全匹配时 TW 为零、局部电荷为零。
- 非理想支路失配下 `P=N` 可以产生残余，结果由实际边沿产生。
- 相同 `P` 的不同位平面组合，在关闭失配时相等；开启各级失配时允许不同。

### T11：电容参与及有限建立

只有一路单位电荷、其余电荷为零，16 个单位跨接电容全部参与共享，理想 `v_sig=1/16`。错误地删去零贡献电容会得到 1，该实现应失败。

再在非理想模式改变保持时长、共享建立时间和寄生，结果应符合对应方程或标定曲线。不得用同一理想期望要求非理想网络强行输出 `1/16`。

### T12：范围、时序和随机复现

分别触发 MR 超限、充电电压超限、参考越界、SG 未稳和比较超时，应产生可定位事件。相同设备、输入、配置与事件种子应复现同一轨迹；改变 `chip_seed` 应只按参数定义改变设备实例。

### T13：标量与张量前向一致

在无噪声整数模式逐 `a/h`、进位、候选值、spike 比较；理想模拟模式再比较边沿、电荷、参考和 margin。有限浮点比较使用按量纲声明的容差，不能只验证最终网络准确率接近。

### T14：训练封装保持前向

相同权重整数、输入、硬件状态、设备实例和噪声事件下，训练封装与独立推理模型的前向 spike 及 `a/h` 必须一致。梯度测试针对指定代理规则与小任务可学习性，不能把替代梯度当作真实硬比较器导数。

### 24.2 实现中不得悄悄加入

- 用一个全局膜电位代替全部局部五路 SCU/MR。
- 把每 Macro 五个 MR 自动替换为一个有符号 MR，或默认做重编码。
- 在位平面、输入折之间提前发放。

- 让实际误发放只影响输出，内部仍按理想状态运行。
- 每个时间步重新抽取固定芯片失配。
- 为了通过物理测试，自动修正真实提供的开关时序。
- 把软件并行批处理、临时数组、观测电压当成额外硬件并行度、缓存或 ADC。
- 给未经标定的模型标注真实芯片面积、能效或延迟精度。

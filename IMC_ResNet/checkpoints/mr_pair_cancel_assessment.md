# Macro 内 MR 等权位配对抵消评估

日期：2026-09-13。用户提出 MR4_b0 与 MR3_b1/MR2_b2/MR1_b3/MR0_b4 配对清零。

## 位编号与数学结论

按当前 INT5 位权，MR0..MR4 分别对应 +1、+2、+4、+8、-16；b0 是该 MR 寄存器最低位。

| 寄存器位 | 粗状态中的贡献 |
|---|---:|
| MR4[0] | -16 |
| MR3[1] | +16 |
| MR2[2] | +16 |
| MR1[3] | +16 |
| MR0[4] | +16 |

实际膜电位贡献还要统一乘 SCU 模量 16，因此每一对是 -256 与 +256。两位同时由 1 清为 0，
逐 Macro 有符号膜电位不变，SCU 余数不变。该操作是精确等权抵消，不是截断真实负膜电位的近似钳位。

多个正位同时为 1 时，只能对每一份负向单位选择一个正位，不能将所有匹配位一起清零。
当前实验采用固定优先级 MR3[1]、MR2[2]、MR1[3]、MR0[4]，未证明这一优先级最优。

## 时序建议

两种实现都已建立独立数值模型：

1. post_add_b0：正常形成候选 MR，再检查 MR4[0]，至多清除一对。
2. carry_intercept_b0：先更新正 MR 候选；在负向进位进入 MR4 前，每个进位单位匹配一个正位。
   未抵消的负向进位正常进入 MR4，再对残余 MR4[0] 做一次配对清零。

示例：旧 MR4=1、MR3=2，又有一个负向进位。先相加会得到 MR4=2，b0=0，失去本轮抵消机会；
提前匹配可得到 MR4=1、MR3=0，二者粗状态都是 -16。

当前 SCU=4 bit，单 fold popcount 最大 36，carry=floor((SCU+count)/16) 可为 0..3。
不能仅用一个布尔 overflow 消费一次就丢掉余下进位。硬件可分拍服务或组合处理，但要保证事务期间不接入下一批更新。

SCU 仍必须保存正确余数；未命中的 MR4 进位不能丢弃。用选中位清零掩码，不能无条件 XOR 翻转。
统一候选状态上匹配，保证正/负两侧同事务写回；全局发放清零优先于抵消/普通提交。

## 下一步重点

- 先实现最低位的四选一原子抵消，并保留完整进位商；估算新增清零写通路和时序成本。
- 单独比较固定优先级与优先选择高 MR 正位平面的策略，不假设相同抵消次数意味着相同峰值。
- 若需清理已进入高位的历史，可扩展 MR4[k] ↔ MR3[k+1]/MR2[k+2]/MR1[k+3]/MR0[k+4]，
  只连接实际存在的寄存器位；这也是等权抵消，但门控和仲裁成本增加。
- b0 方案不能直接消除 MR4=2、MR3=4 这种双方有效位已经上移的状态。
- 若只有真实净负输入、没有匹配正位，必须保留负状态增长；无损抵消不能对任意输入保证固定上界。
- 扩大到128张/全层，再讨论与输入分摊或QAT叠加；若模拟参考由粗和驱动，应由原子提交后的稳定值更新，避免中间清零毛刺。

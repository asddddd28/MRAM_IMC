# Macro 完整膜电位两两交换探索（2026-09-15）

## 交换语义与等效条件

同一层、同一输出通道、同一空间节点、同一逻辑时间边界内，交换两个 Macro 的五路 MR 和五路 SCU，输入映射、权重、位权、物理接收率历史不交换。数学上 U=sum_m sum_b beta_b*(SCU_mb+16*MR_mb)。对 m 做一一置换保持 U 不变；后续固定输入加法和每次精确抵消继续保持全局和。交换改变局部状态，因此必须验证全神经元和，不能要求每个 Macro 仍与原轨迹相等。

各 Macro 必须采用相同状态尺度，交换在本轮更新/判决之后、下一轮输入前原子完成。模型为无泄漏、统一发放硬清零、足够宽整数。模拟 TDP/电容失配、局部量程、在途电荷、串行搬运延迟和能耗未验证；不能将整数守恒等同于物理芯片无误差。

## 对照设置

原始权重，第一层，全空间，T64，诊断索引0,1,2,3,4,5,64,115。保持现有高编号正位转发+b0/b1/b2抵消。每8步交换一次，共7个边界；原始布局8个活跃Macro+8个补零Macro。

- baseline：不交换。
- fixed_active：固定配对0↔4、1↔5、2↔6、3↔7；状态相同则跳过。
- adaptive_active：前8步实际五位面popcount总和排序，高低两两配对；高接收率方的max_b(MR+SCU/16)比低方大4以上才交换；仅8个活跃Macro。
- fixed_all：固定0↔8…7↔15；状态相同则跳过。
- adaptive_all：同上条件，但在全部16个Macro中选择。

另测16×18均摊布局，所有Macro有有效输入，排除仅利用空闲状态容量的解释。每批结果落盘，未完成批次不计入最终结论。

## 活跃度统计

原始映射，全11层，16张测试（上述8张及128:136），每层按实际有效输入行数归一化，排除完全补零Macro。第一层活跃Macro平均接收率最高/最低约1.25，全部层约1.00～1.83。

同空间位置的8步窗口：第一层最活跃Macro/组内均值平均1.805，27.70%的非零窗口超过2；局部接收率CV均值0.493。layer2.conv2相应为2.171、54.95%；layer3.conv1为2.221、60.00%。这些是输入接收率，不是独立Macro发放率；当前一个神经元的发放统一复位全部Macro。

详细数值见macro_input_activity.json，局部窗口计数按输入位置统计，未按输出通道重复计数。

## 硬件含义

完整一对交换的状态载荷为2×5×(MR位宽+4)：5-bit MR为90bit，6-bit MR为100bit，未计地址/握手、RAM读写和路由开销。固定配对不需要频率计数器和排序网络。若已有共享状态RAM/交叉访问，可能在保存恢复时改变状态地址映射；独立本地RAM并不能仅靠改指针免费跨Macro访问。

交换本身不降低瞬时最大值，只改变后续增长及抵消轨迹。局部工作状态不可饱和/截断后再交换，否则信息已丢失。

新增三项交换测试，连同已有测试共76项通过。

## 已完成的8张诊断结果

|---|---|---:|---:|---:|
| 8×36+8空闲 | 不交换 | 33 | 3 | 0 |
| 同上 | 活跃8个固定配对 | 24 | 0 | 4,921,237 |
| 同上 | 活跃8个按频率条件配对 | 31 | 0 | 411,295 |
| 同上 | 全16个固定配对 | 19 | 0 | 9,231,283 |
| 同上 | 全16个按频率条件配对 | 22 | 0 | 1,171,270 |

| 同上 | 按频率条件配对 | 23 | 0 | 597,406 |

每步全神经元整数误差均为0。交换对数是8张×32输出通道×784位置×7交换边界上的累计值，不是单个物理Macro每周期的带宽。

原分配固定全16交换平均每个逻辑输出节点每步载荷64.68bit（按5-bit MR）；条件全16交换约8.21bit。固定方案峰值更低，但搬运更多；二者当前都需5-bit。原分配平均有效MR位数（含补零槽）从0.464升到0.677，因此峰值下降不代表总活跃状态或功耗下降。

原分配中，Macro1平均输入最多（6.865脉冲/步），但MR峰值23；Macro3平均输入5.721，峰值33。平均接收率不是唯一决定量，还受权重bit分布、长期未清零和局部抵消机会影响。

按本次条件交换策略，8步五位面popcount累积的最大值为8×36×5=1440，每Macro需要11-bit统计范围（未计排序逻辑）。固定配对无此需求，硬件实现应先以固定方案作为基准。

## 补充检查与建议

新增测试索引128:136（8张）、原分配、每8步：不交换最大30，活跃8个固定交换25，全16固定交换16；交换方案均无>31观测，逐步全局整数误差0。结合原8张，固定全16交换在16张测试上的最高值19，活跃8个交换最高值25。

原8张诊断集将固定全16交换间隔改为16个逻辑时间步：最大MR仍19，交换3,941,797对，相比8步9,231,283对减少57.30%。16步方案尚未在新增8张复查，不能将其写作16张已验证。

推荐下一候选为固定配对0↔8…7↔15、每16逻辑步交换五MR+五SCU，在更新/判决完成的安全边界执行。进一步应评估就近固定配对、状态RAM访问/恢复周期和更大测试集；不先增加频率排序仲裁。保持全16有输入的均摊布局时，也有30→21的独立收益。

交换只重新分配累积历史，不改变物理Macro接收输入的频率；从某一高负荷Macro看，得到较轻历史后能容纳更多后续输入。原分配空闲Macro参与时，也利用了原本未使用的状态容量。MR下降同时受后续局部抵消轨迹变化影响，本轮未拆分各机制的贡献。

所有回放是第一层整数等价与位宽诊断，采用不饱和的宽整数；未验证模拟失配、真实搬运时延、能耗或全部输入的有限位宽安全。没有重新训练权重或修改正式后端。11层统计是输入活跃度，不是11层交换验证。

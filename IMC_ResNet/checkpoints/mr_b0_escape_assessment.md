# MR4_b0 进位逃逸：事件计数修正

日期：2026-09-13。

## 用户定义及观测时序

逃逸不是“本拍 MR4_b0=1 但没匹配”。本轮计数实际未拦截进位导致 MR4_b0 从 1→0 并向 b1 进位的事件。
每个 SCU 进位单位单独计数，不用更新前后 XOR 代替内部进位事件；IF 复位和配对清零不计逃逸。

对“一直全部为 0”额外追踪每段存活的 b0=1 状态：在正位更新/转发完成、负向进位拦截之前，
四个指定正位是否曾为 1。若曾出现，但被输入负向进位消耗而未清除已有 b0，之后的进位逃逸不纳入严格计数。
新 b0=1 段、复位和已清零状态会重置历史。这里“一直”为各次配对检查时刻的观测，未包含组合逻辑瞬态。

## 结果

同前：第一层、8 张风险样本、T64、原转发+b0/b1/b2，8 个有效 Macro，全空间位置。

| 指标 | 次数 |
|---|---:|
| 实际 b0 向 b1 进位事件（当刻四个正位均为 0） | 2,572,593 |
| 其中，存活期间各检查点四个正位一直全为 0 | 1,637,649 |
| b0 进位前成功拦截 | 5,658,519 |
| 已有 b0 状态成功配对清零 | 1,838,190 |
| 两类 b0 成功抵消合计 | 7,496,709 |

按用户要求的“严格逃逸事件数 / 成功拦截次数”计算：

- 把两类 b0 成功抵消都计入分母：1,637,649 / 7,496,709 = **21.8449%**。
- 分母仅限进位前拦截：1,637,649 / 5,658,519 = **28.9413%**。

如果只要求进位当刻无正位，不要求之前一直没有出现过，事件数为 2,572,593；对应两个比值为 34.3163% / 45.4641%。

这些是用户指定的“逃逸数与拦截数之比”，不是逃逸/(逃逸+拦截)，也不是逐状态检查未命中率。
之前的 94.0433% 只是残余 b0=1 检查的未匹配率，不符合本次事件定义，不应称为这里的逃逸概率。

# 三位逃逸乘积指标

日期：2026-09-14。第一层、8 个风险样本、T64、原转发+b0/b1/b2 抵消，条件与两位统计相同。

沿用用户公式：R3 = ∏[Ek/(Ik+Ek)]，k=0,1,2。
严格逃逸要求对应正位未能出现并配对；分母主口径中 I0 仅计进位前拦截。

| 位 | 严格逃逸进位 Ek | 成功抵消 Ik | Ek/(Ik+Ek) |
|---|---:|---:|---:|
| b0 | 1,637,649 | 5,658,519 | 22.4453% |
| b1 | 323,348 | 1,009,468 | 24.2605% |
| b2 | 60,228 | 27,823 | 68.4013% |

R3 = 22.4453%×24.2605%×68.4013% = **3.72469%**。
这是上一轮两位乘积 5.44535% 再乘 b2 的 68.4013%。
若 I0 包含已有 b0 状态配对清零，R3 = **2.97514%**。

b2 全部向上进位与严格无伙伴进位均为 60,228 次；本轮没有观察到 b2 进位当拍相应正位仍为 1 的事件。
如果 b0/b1 采用全部向上进位而非严格无伙伴定义，三位乘积为 6.49061%（I0 仅进位前拦截）或 5.30572%（I0 含全部抵消）。

这里为用户指定的三个事件比例的乘积，不是逐路径实测的三位连续逃逸概率。
不能据此声称实际负向累积只有该比例到达高位；统计还受复位、未结束的状态和各级事件单位影响。

验证：上一轮所有已有 JSON 字段全部精确复现；逐 Macro 膜电位误差为 0。
b2 向上进位公式 floor(((旧 MR4 mod 8)+未拦截进位)/8) 与逐单位加法在 256 组状态/进位组合上完全一致。
没有修改转发或抵消行为。
